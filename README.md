ระบบจองคิว ศูนย์พักใจ มหาวิทยาลัยพะเยา

เว็บแอปสำหรับนิสิตจองคิวเข้ารับคำปรึกษากับอาจารย์/ผู้ให้คำปรึกษาของศูนย์พักใจ ม.พะเยา และให้อาจารย์จัดการตารางเวลาว่างและอนุมัติคิวได้ในที่เดียว

> **สถานะ:** ต้นแบบ (Prototype) สำหรับทดสอบ ระบบล็อกอินยังเป็นแบบจำลอง ดูหัวข้อ [ข้อจำกัดและแผนพัฒนา](#ข้อจำกัดและแผนพัฒนา)

ฟีเจอร์

สำหรับนิสิต
- **หน้าหลัก** แสดงนัดหมายที่กำลังจะถึงและประวัติล่าสุด
- **จองคิว** เลือกผู้ให้คำปรึกษา เลือกวัน (ล่วงหน้า 10 วัน) และเลือกเวลา โดยช่องที่ถูกจองแล้วหรืออาจารย์ไม่ว่างจะกดไม่ได้
- **คิวของฉัน** ดูสถานะนัดหมาย กรองตาม กำลังจะถึง / ทั้งหมด / ยกเลิกแล้ว และยกเลิกคิวได้
- **ช่องทางติดต่อ** เบอร์โทร อีเมล และ LINE Official Account ของศูนย์

สำหรับอาจารย์ / แพทย์ผู้ให้คำปรึกษา
- **แดชบอร์ด** สรุปจำนวนคิวรอยืนยัน นัดหมายวันนี้ และเคสทั้งหมด พร้อมตัวกรอง
- **อนุมัติ / ปฏิเสธ / ปิดเคส** รายการนัดหมายของนิสิต
- **จัดการตารางเวลา** เปิด-ปิดรับนัดรายช่วงเวลา หรือปิดทั้งวัน

ทั่วไป
- โปรไฟล์ผู้ใช้ (ชื่อ, รูปโปรไฟล์) ประวัติการจอง และออกจากระบบ
- ดีไซน์รองรับมือถือ ใช้ฟอนต์ Noto Serif Thai และ Sarabun

เวลาให้บริการและผู้ให้คำปรึกษา

ช่วงเวลาที่เปิดจอง: `09:00` `10:00` `11:00` `13:00` `14:00` `15:00`

| ผู้ให้คำปรึกษา | ความเชี่ยวชาญ |
|---|---|
| อ.ดร.ธีรภัทร วัฒนสิน | การปรับตัวและความเครียด |
| อาจารย์พิมพ์ชนก วงศ์ทอง | ความสัมพันธ์และครอบครัว |
| อาจารย์กันตพงศ์ ศรีบุญเรือง | การเรียนและการวางแผนชีวิต |

เทคโนโลยีที่ใช้

- **Frontend:** HTML, CSS, JavaScript 
- **ฐานข้อมูล:** [Supabase](https://supabase.com) (ผ่าน `@supabase/supabase-js` v2 จาก CDN)
- **เก็บข้อมูลในเบราว์เซอร์:** `localStorage` (เซสชันล็อกอิน โปรไฟล์ ตารางเวลาว่างของอาจารย์)

โครงสร้างโปรเจกต์

```
Project DB/
├── email.html      # ระบบจองคิวศูนย์พักใจ (ไฟล์หลัก)
├── login.html
└── README.md
```

วิธีเริ่มใช้งาน

1. โคลนโปรเจกต์
   ```bash
   git clone <URL ของ repository>
   cd "Project DB"
   ```
2. เปิด `email.html` ด้วยเบราว์เซอร์ หรือใช้ **Live Server** ใน VS Code (คลิกขวาที่ไฟล์ แล้วเลือก *Open with Live Server*)
3. ต้องต่อเน็ตเพื่อโหลดฟอนต์ ไลบรารี Supabase และข้อมูลการจอง

การตั้งค่า Supabase

ค่าเชื่อมต่ออยู่ในส่วน `<script>` ของ `email.html`:

```js
const SUPABASE_URL = '...';
const SUPABASE_ANON_KEY = '...';
```

หากต้องการใช้โปรเจกต์ Supabase ของตัวเอง ให้สร้างตาราง `bookings` ตามโครงสร้างนี้

| คอลัมน์ | ชนิด | คำอธิบาย |
|---|---|---|
| `id` | uuid / bigint (PK) | รหัสการจอง |
| `user_id` | text | อีเมลผู้จอง |
| `counselor_id` | text | `c1`, `c2` หรือ `c3` |
| `student_name` | text | ชื่อนิสิตที่แสดงในรายการ |
| `booking_date` | date / text | วันนัด (`YYYY-MM-DD`) |
| `booking_time` | text | เวลานัด เช่น `09:00` |
| `status` | text | `pending`, `confirmed`, `cancelled`, `completed` |
| `created_at` | timestamptz | เวลาที่สร้าง (default `now()`) |

แล้วเปิด Row Level Security พร้อมกำหนด policy ให้เหมาะสมกับการอ่าน/เขียนของแต่ละบทบาท

ขั้นตอนการทำงาน

นิสิตเลือกอาจารย์/วัน/เวลา  →  ส่งคำขอจอง (pending)
        →  อาจารย์อนุมัติ (confirmed) หรือปฏิเสธ
        →  นัดหมายเสร็จสิ้น (completed)

ข้อจำกัดและแผนพัฒนา

- [ ] **ล็อกอินยังเป็นแบบจำลอง** รับเฉพาะอีเมลทดสอบสองบัญชีและไม่ตรวจรหัสผ่านจริง ควรเปลี่ยนเป็น Supabase Auth หรือ SSO ของมหาวิทยาลัย
- [ ] **การอนุมัติ/ปฏิเสธบางส่วนยังบันทึกแค่ใน `localStorage`** ยังไม่ซิงค์ขึ้น Supabase ทุกจุด ควรเรียกใช้ `updateStatus()` ให้ครบทุกการเปลี่ยนสถานะ
- [ ] **ตารางเวลาว่างของอาจารย์เก็บใน `localStorage`** นิสิตคนอื่นจะไม่เห็นการปิด-เปิดเวลา ควรย้ายไปเก็บใน Supabase
- [ ] ตั้งค่า **Row Level Security** ของตาราง `bookings` ให้รัดกุมก่อนใช้งานจริง
- [ ] เพิ่มการแจ้งเตือนทางอีเมล/LINE เมื่อมีคิวใหม่หรือสถานะเปลี่ยน
- [ ] แยกไฟล์ CSS/JS ออกจาก HTML เพื่อดูแลโค้ดง่ายขึ้น
