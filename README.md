ระบบจองคิวศูนย์พักใจ มหาวิทยาลัยพะเยา

ต้นแบบ (Prototype) หน้าเว็บสำหรับ นิสิต ใช้ตรวจสอบเวลาว่างของผู้ให้คำปรึกษา จองคิว เลื่อนนัด ยกเลิกนัด และดูประวัติการจอง ของศูนย์พักใจ มหาวิทยาลัยพะเยา

โปรเจกต์รายวิชา 227202 พื้นฐานของระบบฐานข้อมูล (Fundamental of Database System) สาขาวิชาวิศวกรรมซอฟต์แวร์ คณะเทคโนโลยีสารสนเทศและการสื่อสาร มหาวิทยาลัยพะเยา

หมายเหตุ: เวอร์ชันนี้เป็นเดโมฝั่ง Frontend เท่านั้น ยังไม่มี Backend หรือฐานข้อมูลจริง ข้อมูลทั้งหมดเป็นข้อมูลจำลอง และบันทึกไว้ในเบราว์เซอร์ของผู้ใช้ (localStorage)
